# Notes de version v0.8.3

Date de publication : 2026-10-14

La v0.8.3 facilite la **recherche et l’usage des images** dans les docs : galerie, embedding multimodal pour interroger le contenu visuel. Les citations ouvrent l’**original** ; l’agent lit les **pièces jointes** à la demande. Wiki : graphe par **groupes** ; admin utilisateurs, catalogue modèles, source **Seafile** ; stabilité parsing, retrieval et sync.

Avant migration depuis v0.8.2 : [Notes de mise à niveau](#upgrade-notes). [CHANGELOG](https://github.com/Tencent/WeKnora/blob/main/CHANGELOG.md).

## Embedding multimodal {#multimodal-embedding}

Texte et images dans le retrieval ; questions texte → graphiques/screenshots pertinents.

Exemples : Tencent WeMM-Embedding, Qwen3-VL-Embedding ; presets WeMM 2B/4B/9B + script Transformers ou vLLM.

<Screenshot src="/screenshots/kb-image-vector-settings.png" caption="Activer le vecteur image dans le traitement d’images KB" hint="Modèle vectoriel, multimodal, interrupteur image ; ex. WeMM." />

## Autres changements {#other-changes}

- **Parse** : AnyDoc 0.2.4, MinerU 4.0 V1 ; EPUB, PPTX, Excel, tables MD.
- **Images** : OCR conditionnel ; rejet OCR dupliqué/vide/tronqué ; trace d’échec.
- **Retrieval** : rerank unifié API/QA, seuils, diagnostics ; tri, copie index, bulk.
- **Graphe** : direction relations, troncature explicite.
- **Accès** : analytics KB partagée ; admin gère sessions canal ; échec save credentials ≠ login OK.
- **Sync** : Notion, Yuque, IMA, Feishu, GitLab, RSS — pagination, retry, pas de fantômes après purge source.
- **Agent/session** : file d’attente, compression ; timeouts modèle.
- **IM/CLI/SDK** : WeCom, Feishu, Yunzhijia ; CLI upload récursif ; Go SDK stream ; `model_id` réel dans event completion.
- **Deploy/UI** : ParadeDB `v0.25.11-pg17`, Helm ; zh-TW ; styles unifiés.

## Notes de mise à niveau {#upgrade-notes}

Sauvegarder DB, fichiers, config ; voir [Installation](../01-getting-started/02-installation.md). Garder `SYSTEM_AES_KEY`, JWT, clés signature. Si &lt; v0.8.2 : [v0.8.2](v0.8.2.md#upgrade-notes).

| Changement | Action |
| --- | --- |
| PG `000111`–`000118`, SQLite `000031`–`000036` | `000113` galerie ; `000112` index embeddings — `CONCURRENTLY` possible, voir [Schéma DB](../06-development/02-database-schema.md) |
| ParadeDB / extensions | Image compatible avant migration ; `000115` pg_search 0.25.11 / vector 0.8.4 — **ne pas** rejouer commandes 0.22.6 sur nouvelle image ; [Upgrade ParadeDB](../01-getting-started/06-paradedb-upgrade.md) |
| `invite_only` sans register-by-invite | Passer à `invite_register` si besoin ; `DISABLE_REGISTRATION=true` = pas d’inscription |
| `allowed_tools: []` | Plus « outils par défaut » ; migration agents ; null/omit pour défaut |
| Vecteur image off | Activer modèle + reparse ; changement encodage Qwen3-VL/WeMM → rebuild vecteurs |
| Citations précises | Reparse pour page/paragraphe ; sinon fallback texte |
| MCP OAuth timestamps | UTC timezone ; re-auth si offset legacy |
| Pièces jointes | Rétention si fil référence ; TTL si non référencées |
| Terminal Docker | Shell tué à déconnexion — `nohup`/systemd pour jobs longs |
