# Notes de version v0.8.2

Date de publication : 2026-09-24

La v0.8.2 sort l’agent du seul chat : contrôle du **navigateur local**, publication de la KB en **MCP Server** pour Claude, Cursor, etc. ; conversation **pilotable** (file d’attente, bifurcation, rollback). Sandbox : terminal interactif et bureau graphique ; modèles via **catalogue fournisseur** ; Confluence, DingTalk Docs, interface japonaise.

Avant migration depuis v0.8.0 : [Notes de mise à niveau](#upgrade-notes). [CHANGELOG](https://github.com/Tencent/WeKnora/blob/main/CHANGELOG.md).

## Navigateur local {#local-browser}

Le raisonnement intelligent peut piloter Chrome ou Edge sur votre machine. Connexion via l’extension [BrowserSkill](https://github.com/Tencent/BrowserSkill) ; l’agent ouvre pages, clics, formulaires, lit le contenu et rapporte dans le fil.

<Screenshot
  src="/screenshots/local-browser-task.png"
  caption="L’agent consulte la dernière release GitHub puis remplit un formulaire ; aperçu tâche en bas à droite" />

- **Contrôle dans le fil** : pause, reprise, arrêt ; saut vers la page dans le navigateur.
- **Main humaine** : login, CAPTCHA, autorisations → assistance manuelle puis reprise.
- **Appairage unique** : « Boîte à outils → Connexion navigateur », lien dans l’extension ; plusieurs fils du même espace partagent l’autorisation ; activer « Navigateur local » dans la zone de saisie.

<Screenshot
  src="/screenshots/browser-connection.png"
  caption="Boîte à outils → Connexion navigateur : version extension, état, actions web autorisées" />

L’image Docker app inclut BrowserSkill ; multi-réplicas : adresses inter-nœuds et clé partagée. Voir [Navigateur local](../05-clients/09-local-browser.md).

## MCP Server intégré {#mcp-server}

Chaque espace peut exposer ses KB en MCP pour Claude Desktop, Cursor, Claude Code, VS Code, sans processus MCP séparé.

<Screenshot
  src="/screenshots/mcp-server-endpoint.png"
  caption="Paramètres → Intégrations → MCP Server : URL et config client" />

- Créer un endpoint, choisir KB et outils (quatre groupes : recherche/lecture, Q&R agent, Wiki, écriture — écriture off par défaut).
- Jeton et quota par endpoint (défaut 60/min), rotation possible.
- Snippets Cursor, VS Code, Claude Desktop ; one-liner Claude Code.

Le `mcp-server/` Python du dépôt est **déprécié**. Voir [MCP](../03-features/08-mcp.md#clients-externes).

## Notes de mise à niveau {#upgrade-notes}

| Changement | Action |
| --- | --- |
| `.env.example` sans défaut `JWT_SECRET`/`SYSTEM_AES_KEY` ; `SYSTEM_SIGNING_KEY` | Nouveau déploiement : générer les secrets. **Conserver `SYSTEM_AES_KEY`** existant. Sans `JWT_SECRET` fixe : token invalide au restart / multi-réplicas |
| DingTalk IM : Stream uniquement | Migration `000096` webhook→Stream ; activer Stream dans la console DingTalk |
| Commandes sandbox en `root` (v0.8.0 : uid 1000) | Un sandbox par fil ; scripts dépendant d’un user non-root à adapter |
| MCP `usage_instructions` si envoyé | Non vide, ≤16000 car. ; omis = conserver l’existant |
| Invitations org : recherche par ID espace uniquement | Plus de recherche par nom |
| Go SDK `UpdateAgentRequest.Avatar` → `*string` | `nil` = garder ; `""` = effacer |

Migrations PG `000091`–`000110`, SQLite `000013`–`000030`. `000106` index `CONCURRENTLY` — si interrompu, voir [Dépannage](../01-getting-started/05-troubleshooting.md). ParadeDB sans AVX2 ; MinIO depuis `quay.io`.

## Autres changements {#other-changes}

- **Agent** : outils fusionnés `search_knowledge`, `read_document`, `list_documents` ; historique rogné à la fenêtre ; MCP à la demande ; catalogue outils persistant par service.
- **Skills** : upgrade sans rollback répertoire ; vérif deps runtime après install.
- **Wiki** : reprise si rewrite tronqué ; réutilisation page même titre ; chunks cités avec légendes images.
- **Retrieval/parse** : Milvus BM25 multilingue ; plafonds Neo4j ; timeout PaddleOCR-VL ; PDF + anydoc = builtin par défaut ; tables HTML inline sans chunks géants.
- **Stabilité** : docs bloqués processing/deleting ; fermeture accès cross-espace org partagée ; Wiki tenant supprimé ; formats vector/rerank/chat alignés docs officielles.
