# Manuel employé (extrait) — remboursements et congés

**Date d’effet** : 2024-01-01  
**Public** : employés permanents NovaTech  
**Services responsables** : RH · Finance

## 1. Remboursement des déplacements professionnels

### 1.1 Transport

| Niveau | Avion | Train grande vitesse | Transport local |
| --- | --- | --- | --- |
| M3 et plus | Économique | Première | Frais réels, plafond 300 ¥/jour |
| M1–M2 | Économique | Seconde | Frais réels, plafond 200 ¥/jour |
| Autres | Économique (approbation 3 j à l’avance) | Seconde | Frais réels, plafond 150 ¥/jour |

**Règles** :

- Billets d’avion via la plateforme voyages d’entreprise ; achat perso remboursable sous 7 jours ouvrés après le trajet.
- Train > 6 h consécutives : surclassement première possible avec approbation e-mail du manager.

### 1.2 Hébergement

| Catégorie de ville | Plafond / nuit (TTC) |
| --- | --- |
| Tier 1 (Pékin, Shanghai, Guangzhou, Shenzhen) | 600 ¥ |
| « New tier 1 » | 450 ¥ |
| Autres | 350 ¥ |

Dépassement à charge du salarié sauf organisation officielle avec dérogation Finance.

### 1.3 Repas et indemnités

- Pas de remboursement séparé des repas en mission ; **indemnité journalière** :
  - Tier 1 Chine : 150 ¥ / jour
  - Autres villes Chine : 120 ¥ / jour
  - Étranger : barème Finance du mois
- Repas clients : workflow **frais de représentation**, distinct du voyage.

## 2. Remboursements courants

### 2.1 Délai de soumission

Factures dans les **30 jours** suivant la dépense via OA. Retard : double signature manager + responsable Finance.

### 2.2 Postes fréquents

| Poste | Description | Pièces |
| --- | --- | --- |
| Fournitures bureau | Unité < 500 ¥ | Facture + liste d’achat |
| Formation | Certifications, conférences | Facture + convocation + attestation |
| Matériel de test | Prototypes, capteurs R&D | Facture + n° projet + fiche d’immobilisation |

Les achats hardware domotique / capteurs pour tests R&D exigent une fiche « prototype R&D » dans le système d’actifs avant remboursement. Se référer au *Manuel produit — Hub domotique Pro* pour modèle et specs.

## 3. Congés annuels et absences

### 3.1 Durée

Selon ancienneté (date d’entrée) :

| Ancienneté | Jours / an |
| --- | --- |
| < 1 an | 5 |
| 1–10 ans | 10 |
| > 10 ans | 15 |

Embauche avant le 31 mars : prorata année en cours ; après → plein droit l’année suivante.

### 3.2 Processus

1. Demande OA à l’avance (congé payé, maladie, personnel, etc.).
2. ≤ 3 j : manager ; 3–7 j : directeur de département ; > 7 j : enregistrement RH.
3. Maladie > 2 j consécutifs : certificat hôpital niveau 2 minimum.

### 3.3 Conflits projet

En cas de release figée (ex. firmware 3.5 grise, acceptance POC KB), annoncer dans le canal projet et nommer un **relais**. Absences équipe POC Zhang Ming : informer aussi Chen Hao (directeur produit).

## 4. Sanctions

- Fausses factures / doubles remboursements : remboursement + régime disciplinaire.
- Voyage international non approuvé : frais non remboursés.
